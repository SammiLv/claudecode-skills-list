# AI 工具一周工作总结

## Overview

从当前 AI 工具的会话记录中，提取过去 7 天的工作内容，生成一份简洁实用的中文周工作总结。聚焦实际完成的工作主题、产出物、验证情况和待跟进事项。

## Workflow

1. **确定时间范围**
   - 固定为：当前日期往回 7 天（含今天），例如今天是 2026-05-21，则范围为 2026-05-15 至 2026-05-21。
   - 不使用"本周一到今天"的自然周逻辑，始终用滚动 7 天。

2. **识别当前 AI 工具**
   - 根据当前运行环境自动判断工具名称（如 claudecode、cursor、codex、workbuddy 等）。
   - 工具名称全小写、无空格，用于报告标题和钉钉文档命名。

3. **收集会话记录**
   - **Claude Code — 优先读取 memory 文件**：读取 `~/.claude/projects/*/memory/YYYY-MM-DD.md`（目标日期范围内每天），以及 `~/.claude/projects/*/memory/MEMORY.md` 获取长期上下文。逐日检查，缺失日期静默跳过。
   - **Claude Code — memory 文件缺失时回退读取 JSONL（两步走）**：
     - 第一步：读取 `~/.claude/history.jsonl`，按 `timestamp` 字段筛选 7 天内的条目，收集涉及的 `project` 路径和 `sessionId`。`history.jsonl` 每行格式为 `{"display":"用户输入","timestamp":毫秒时间戳,"project":"/绝对路径","sessionId":"uuid"}`。
     - 第二步：将 `project` 路径转换为 `~/.claude/projects/` 下对应的目录（路径中 `/` 替换为 `-`），读取匹配 `sessionId` 的 `.jsonl` 文件。每个 JSONL 文件每行是一条消息，只提取 `type: user` 且 `message.content` 为纯文本的请求描述，跳过 tool_result、报错等噪音。
     - 此方式可覆盖用户在所有项目目录下的工作，不遗漏跨项目内容。
   - **其他 AI 工具**：读取该工具对应的本地会话记录或日志文件（路径因工具而异）。
   - 不使用网络访问。

4. **提取有效信息**
   - 优先提取：任务描述、完成事项、创建或修改的文件路径、关键决策。
   - 跳过：中间搜索结果、临时文件路径、工具报错等过程噪音。

5. **按工作主题汇总（不按天）**
   - 将同一项目或任务的多天记录合并为一条。
   - 区分：已完成、部分完成、受阻、仅调研。
   - 日期作为辅助上下文，不作为主结构。

6. **输出**
   - **默认**：直接在当前会话中生成报告。
   - **写入钉钉**：若触发时附带了钉钉文件夹链接，则将报告写入该文件夹下的钉钉文档。
     - 文档标题：工具名称（无空格）+ 一周工作总结，例如 `claudecode一周工作总结`。
     - **创建前必须先搜索同名文档**：使用 dingtalk-doc-mcp 在目标文件夹下搜索与目标标题完全匹配的文档。
       - 若找到同名文档：先调用删除接口将其删除，再新建。
       - 若未找到同名文档：直接新建。
     - 完成后在当前会话显示文档链接。

## Report Format

```markdown
**{工具名称}一周工作总结｜{开始日期} 至 {结束日期}**

本周主要完成了：

1. 项目/主题：一句话说明做了什么。
   产出：列出关键文件、文档、skill、脚本、页面或结论。
   验证：列出运行过的检查；如果没有验证，写"未单独验证"。

2. ...

**本周重点产出**
- 可交付文件、页面、脚本、skill、文档或明确结论。

**待跟进**
- 明确的下一步、风险或需要用户确认的事项；没有就写"暂无明确待跟进项"。
```

## Quality Bar

- 具体到让用户无需重新打开每个会话就能回忆起这周的工作。
- 只在路径是有价值的产出物或变更文件时才提及路径。
- 不引用 token、密钥、私有配置值或完整消息体。
- 不做推测，仅凭记录说话；证据不足时用"看起来"或"可能"标注。
- 若目标日期范围内没有找到任何有效会话记录，明确说明并列出已检查的日期。

## Resources

- `~/.claude/projects/*/memory/YYYY-MM-DD.md`：Claude Code 每次完成实质性工作后写入的日记文件。
- `~/.claude/projects/*/memory/MEMORY.md`：长期记忆索引，包含用户偏好和项目约定。
